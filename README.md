# sum_agent

Pull-based agent for OpenSUM. Runs on every managed host, polls [[sum_server]] (or a [[sum_satellite]]) for signed jobs, verifies the signature, executes the work, and reports results. **Never opens a listening port.** Loads signed external plugins as subprocesses that speak line-delimited JSON-RPC 2.0 over stdio.

- Product spec: see `../Obsidian/` (source of truth).
- Cross-component guidance: `../CLAUDE.md`.
- Tech stack and rationale: `[[Tech Stack]]` in the Obsidian vault.

## Status

**Pre-alpha.** Linux only. Built-in capabilities: `rename_nic`, `mount_disk`. Plugin runtime works against a **local** plugin cache; network fetch from the server is deferred.

## Layout

```
src/sum_agent/
├── cli.py              # sum-agent enroll|run|inventory|version
├── settings.py
├── core/               # state, http, logging, errors, verify, canonical
├── inventory/          # cpu, memory, disks, nics, gpu, snapshot
├── jobs/               # verify, registry, dispatch, builtins/{rename_nic, mount_disk}
├── plugins/            # manifest, cache, runtime (JSON-RPC subprocess)
├── client.py           # API wrappers
└── runner.py           # main async loop
```

## Install

Requires Python 3.12+ and `uv`.

```sh
uv sync --extra dev
```

## CLI

```sh
# Print one-shot inventory (no network).
uv run sum-agent inventory --pretty

# Enroll with a one-time token from the server.
uv run sum-agent enroll \
    --server-url https://sum-server.example.com:8443 \
    --token <one-time-enrollment-token>

# Run the daemon.
uv run sum-agent run

uv run sum-agent version
```

`enroll` writes `$SUM_AGENT_STATE_DIR/state.json` (mode `0600`) containing the long-lived agent bearer token and the server's Ed25519 public key. `run` requires this file to exist.

## Plugins (local cache)

Each plugin is a directory under `$SUM_AGENT_PLUGINS_DIR`:

```
<name>-<version>/
├── manifest.json    # signed; declares capabilities, supported (os, arch), binary_sha256
└── <executable>     # the binary the manifest's entrypoint points at
```

The manifest is signed with one of the keys listed in `SUM_AGENT_TRUSTED_PLUGIN_KEYS`. The binary's SHA-256 is also bound by the signature. At startup the agent verifies every plugin in the cache; failures are logged and the plugin is skipped.

The plugin executable speaks line-delimited JSON-RPC 2.0 over stdin/stdout. See `tests/unit/test_plugin_subprocess.py` for a minimal reference plugin.

## Running as a systemd service

Not generated by this package. Sketch:

```ini
[Unit]
Description=OpenSUM agent
After=network-online.target

[Service]
Type=simple
User=sum-agent
EnvironmentFile=/etc/sum-agent.env
ExecStart=/usr/local/bin/sum-agent run
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

Most built-ins (rename_nic, mount_disk) need root or `CAP_NET_ADMIN` + `CAP_SYS_ADMIN`; run accordingly.
