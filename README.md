# sum_agent

Pull-based inventory agent for OpenSUM. Runs on every managed host, collects hardware components and system facts, reports them to sum_server, and heartbeats so the server can show live presence (online, unreachable, rebooting, powered off, stopped). On SIGTERM it classifies the shutdown via systemd and sends a final goodbye report. All communication is initiated outbound by the agent. **Never opens a listening port.**

## Status

**Pre-alpha.** Linux only. Collects disks, NICs, CPUs, GPUs, and memory as components, plus host-level facts (OS, kernel, hostname, addressing, virtualization).

## Layout

```
src/sum_agent/
├── cli.py              # sum-agent enroll|run|inventory|version
├── settings.py
├── core/               # state, http, logging, errors, verify, canonical
├── inventory/          # collectors + snapshot orchestrator
├── client.py           # API wrappers
└── runner.py           # main async loop
```

## Install

Requires Python 3.12+ and `uv`.

```sh
uv sync --extra dev
```

## CLI

```sh
# Print one-shot inventory (no network).
uv run sum-agent inventory --pretty

# Enroll with a one-time token from the server.
uv run sum-agent enroll \
    --server-url https://sum-server.example.com:8443 \
    --token <one-time-enrollment-token>

# Run the daemon.
uv run sum-agent run

uv run sum-agent version
```

`enroll` writes `$SUM_AGENT_STATE_DIR/state.json` (mode `0600`) containing the long-lived agent bearer token and the server's Ed25519 public key. `run` requires this file to exist.

The server's web UI generates these commands (with a fresh token) when you enroll a new host.

## Running as a systemd service

Not generated by this package. Sketch:

```ini
[Unit]
Description=OpenSUM agent
Wants=network-online.target
After=network-online.target

[Service]
Type=simple
User=sum-agent
EnvironmentFile=/etc/sum-agent.env
ExecStart=/usr/local/bin/sum-agent run
Restart=on-failure

[Install]
WantedBy=multi-user.target
```
